# 🗣️ Telegram Text-to-Speech (TTS) Bot

A lightweight, powerful Telegram bot built with Python that instantly converts any text message into a high-quality native Telegram voice note using Google TTS (`gTTS`).

---

## 🚀 Features
* ⚡ **Instant Conversion:** Turn ad copy, articles, or messages into speech in seconds.
* 🎤 **Native Voice Format:** Sends the audio back as an easy-to-play Telegram voice note.
* 🧼 **Auto Clean-up:** Automatically deletes audio files from the server memory after sending to keep the system fast.

---

## 🛠️ Tech Stack & Requirements
* **Language:** Python 3.11.9
* **Libraries:** `python-telegram-bot`, `gTTS`, `requests`
* **Hosting Platform:** Render
